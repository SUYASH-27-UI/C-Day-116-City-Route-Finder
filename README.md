# C Day 116 – City Route Finder

## Project Description
A C application that finds the shortest route between two cities using Dijkstra's shortest path algorithm.

## Features
- Displays five sample cities.
- Represents roads using a weighted graph.
- Finds the shortest route.
- Displays the complete route.
- Calculates total distance.
- Handles unreachable destinations.

## Technologies Used
- C Programming
- Graphs
- Adjacency Matrix
- Dijkstra's Algorithm
- Arrays
- Functions

## How to Run
Compile using `gcc route_finder.c -o route_finder`.

Run using `./route_finder`.

## Learning Outcomes
Learned graph representation, weighted edges, greedy algorithms, shortest path calculation, and path reconstruction.

## Note
The city distances are illustrative sample values and are not live navigation data.
